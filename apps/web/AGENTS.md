# Alcance web

- Extender el sistema visual existente; una sola React PWA y rutas lazy por módulo.
- Mantener permisos y módulos como filtros UX, sin sustituir autorización backend.
- Formularios móviles táctiles, foco visible, movimiento reducido y cero overflow horizontal.
- IndexedDB guarda borradores versionados por usuario y empresa, nunca tokens ni detalle médico.
- Mapas, IA y OCR se cargan solo al abrir módulos habilitados.
- Probar Chromium escritorio, Pixel 7 y al menos un motor alternativo.
