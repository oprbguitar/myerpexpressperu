Esta versión incorpora:

- el módulo operativo de gestión de residuos con nueve fases, timeline y
  excepciones;

- una interfaz adaptable con inspector contextual;
- scripts de ejecución para Windows, Linux y macOS;
- migraciones `0001`–`0015`.

El cierre interno de residuos permanece bloqueado hasta contar con evidencia
documental vinculada, aprobación segregada y reglas específicas.

## Inicio rápido

### Windows PowerShell

```powershell
Expand-Archive .\erp-express-peru-demo-v0.4.0.zip
Set-Location .\erp-express-peru-demo-portable-v0.4.0
.\demo-start.ps1
.\demo-status.ps1
```

### Linux y macOS

```bash
unzip erp-express-peru-demo-v0.4.0.zip
cd erp-express-peru-demo-portable-v0.4.0
chmod +x demo-*.sh
./demo-start.sh
./demo-status.sh
```

Abra `http://localhost:18080/demo/`.
