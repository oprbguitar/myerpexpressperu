# Reglas y notificaciones

Las reglas de negocio se modelan como definiciones versionadas, activaciones,
ejecuciones, pasos e historial. El módulo permanece deshabilitado por defecto
hasta completar un simulador administrativo de extremo a extremo.

El worker genera notificaciones idempotentes para cuentas por cobrar, pagos,
stock, comprobantes rechazados, tareas de proyecto vencidas, acciones correctivas
SST, mantenimiento, revisión OCR y proveedores no disponibles. No ejecuta
decisiones laborales, clínicas, fiscales ni financieras por medio de IA.
